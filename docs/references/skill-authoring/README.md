# Skill Authoring Reference

This directory stores reference material for writing and maintaining skills.

## Repository Policy

This repository's skills follow conventions informed by external skill-authoring guides, including Anthropic's "The Complete Guide to Building Skills for Claude".

The repository does not publish copied guide text or PDFs unless redistribution rights are clear.

## Local Reference Convention

If you keep a private local reference copy for maintenance work, use:

- `The-Complete-Guide-to-Building-Skill-for-Claude.md`
- `assets/The-Complete-Guide-to-Building-Skill-for-Claude.pdf`

Those files are intended for local lookup only and are ignored by git in this repository.
